# Student Management System

## Project Overview
The Student Management System is a Python-based application
that helps users manage student records.

## Features
- Add new student records
- View all students
- Search students by ID
- Validate student details
- Handle invalid inputs and file errors
- Store student records in a CSV file

## Technologies Used
- Python
- CSV Module
- OS Module

## Requirements
- Python 3 installed
- Visual Studio Code (recommended)

## How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

   python3 main.py

## Data Storage
Student records are stored in students.csv.
The file is created automatically when the program starts.
